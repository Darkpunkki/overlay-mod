Challenge

Route

Route files live in appdata/routes and are plain JSON — edit them freely, then reload.

The challenge here is only this route's default — whichever you pick at the top of the page still wins.

Renaming a route starts its personal bests over, because they are filed under its name.

    A boss from the list brings its event flag with it, so that split advances on its own. Anything you type has no flag and needs the split hotkey — which is a perfectly good way to run, just not a surprise you want when you meant to add Vordt.

    Built-in routes are only written when the folder is empty, so deleting one keeps it deleted. Restore writes back any that are missing — including routes added in a newer version.

    Split names

    What the overlay calls each split, where you would rather it said something shorter. Leave a box empty to use the name from the route.

    Only the display changes. Personal bests are filed under the name in the route file, so renaming here never loses the history behind a boss — which is why this exists instead of editing the route.

    Run

    Runs start on their own when you load into the world. These are for when you need to override that, and for splits with no known boss flag.

    Global hotkeys work while the game has focus. Change them in appdata/hotkeys.json and restart the host.

    Attempts

    Counted per route and challenge, and it goes up whenever a run starts — loading in, a reset, or a fresh character. Set it by hand if you are arriving with a tally from somewhere else.

    Appearance

    Changes apply straight away, in the browser and in OBS. The preview sits on a chequerboard so you can see what is transparent.

    Splits shown

    How many boss names the overlay shows at once. The list scrolls through longer routes, so this is the overlay's height, not the route's length — set it to the full split count to show a whole route with no scrolling.

    Sits beside the challenge name. Nothing is shown until the first attempt.

    What counts as a hit

    Only the No Hit challenge uses any of this. Two things get set aside: what the ground did to you, and what poison did. Both are worked out from health and position over time rather than read from the game, so the thresholds are yours to move. Every other challenge counts all damage regardless.

    Falls

    Poison, toxic and anything else that ticks

    Recognised as a metronome: four or more small bites of about the same size, at gaps that are about the same as each other. Poison and toxic tick once a second, every second; combat never does, so the evenness is what gives it away rather than the speed. Anything that really hurts is over the size below and counts as a hit on sight.

    Because it takes a fourth bite to see the rhythm, the first three wait a couple of seconds before being called — so a genuinely small hit shows up late rather than a poison tick showing up at all. Standing in a fire will be called poison too.

    Recent damage, newest first, with the health lost and the drop measured for each. This is how you check the detectors rather than trust them: if a real hit is showing as a fall, raise the distance or shorten the window; if one is showing as poison, lower the bite size. If poison is still showing as a hit, compare its HP against the ceiling below and raise the bite size past it.

    Refresh to see what the bite size works out to.
