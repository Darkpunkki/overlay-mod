OverlayMod

Pick what you're running. The overlay updates immediately.

Challenge

Decides what the overlay shows and what your runs are ranked by.

Route

Route files live in appdata/routes and are plain JSON — edit them freely, then reload.

Built-in routes are only written when the folder is empty, so deleting one keeps it deleted. Restore writes back any that are missing — including routes added in a newer version.

Run

Runs start on their own when you load into the world. These are for when you need to override that, and for splits with no known boss flag.

Global hotkeys work while the game has focus. Change them in appdata/hotkeys.json and restart the host.

Appearance

Changes apply straight away, in the browser and in OBS. The preview sits on a chequerboard so you can see what is transparent.

Splits shown

How many boss names the overlay shows at once. The list scrolls through longer routes, so this is the overlay's height, not the route's length — set it to the full split count to show a whole route with no scrolling.

What counts as a hit

Only the No Hit challenge uses any of this. Two things get set aside: what the ground did to you, and what poison did. Both are worked out from health and position over time rather than read from the game, so the thresholds are yours to move. Every other challenge counts all damage regardless.

Falls

Poison, toxic and anything else that ticks

Recognised by shape, not by cause: three or more small bites of about the same size, spaced at least 1.2 s apart. A combo lands far quicker than that, and anything that really hurts is over the size below. Because it takes a third bite to be sure, the first two wait a few seconds before being called — so a genuinely small hit shows up late rather than a poison tick showing up at all. Standing in a fire will be called poison too.

Recent damage, newest first, with the health lost and the drop measured for each. This is how you check the detectors rather than trust them: if a real hit is showing as a fall, raise the distance or shorten the window; if one is showing as poison, lower the bite size.

Shut down
